# Squadmint Launchpad

Build minions.quest, an AI memecoin launchpad and agency platform on Solana.

Every coin launched receives an autonomous squad of 7 specialized AI minions:
1. Atlas - Squad Commander (Strategy & Director)
2. Cipher - Scout / Recon (Market Intelligence & Trends)
3. Pixel - Alchemist (Meme Art, Banners & Visuals)
4. Nova - Bard (Lore, Hooks & Copywriting)
5. Echo - Raid Leader (Social & Distribution)
6. Forge - Architect (Web Portal & Live Terminal)
7. Blitz - Treasurer (Growth, Listings & Buyback/Burn Rituals)

Key pages and features:
- Home / Command Deck: Hero section, live minion activity terminal, featured tokens, platform stats (total coins, burns, quests completed), and "Meet the Squad" interactive roster.
- Token Launch Portal: Form for token name, ticker, mascot upload, art style selector, pair selection, slippage, and optional dev buy with curve preview.
- Live Quest Board / Token Directory: Interactive board of launched tokens with filters (Trending, Near Graduation, Fresh Mints), bonding curve progress bars, squad quest levels, and market caps.
- Token HQ (Detail View): Dedicated coin view with live candlestick/line chart, buy/sell swap widget, bonding curve status, minion live feed (showing ongoing work and generated memes from the 7 agents), and fee burn receipts.
- Agent Roster Page: Detailed breakdown of the 7 minions, their abilities, and live mission logs.

Design: Dark mode, sleek cyberpunk/RPG quest aesthetic with modern Web3 UI components and lively status animations.
